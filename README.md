# MUST 人文藝術學院本科教育品牌網站

面向本科新生家長的課程網站設計原型。本倉庫保存 V11 響應式手機版的單文件源碼。

## 在線演示

https://must-fa-v11-mobile-demo.netlify.app/

## 本地查看

下載 `index.html`，使用瀏覽器打開。CSS、JavaScript 和圖像資源內嵌在 HTML 中，無需安裝依賴或執行構建。打開其中的外部網站链接仍需聯網。

## 文件

- `index.html`：現有 V11 手機版網站源碼，未修改頁面內容、樣式或交互。
- `README.md`：本文件。
